For the User

Navbar

Users can navigate around the website by using the links located on the blue bar on the top of the page.

Cart

Each page has different items that the user can add to their cart.
The cart can be located on the right hand side of the page.

The quantity of items in the cart can be modified by using the number input like this -->
Alternatively, you can enter your own number into the number input.

An item in the cart can be removed by clicking the blue 'x' button next to its price like this --> x

Voucher

A voucher code can be entered by typing the voucher code on the right hand side of the page inside the designated box that looks like the following:

Please note that the only available codes are the following:
- "HELLOWORLD" (20% Discount)
- "FREEPIZZA" (100% Discount)

They should be case-sensitive. Do not include the quotation marks as part of the voucher code.

Then, click the 'SUBMIT' button to submit the voucher code, and apply the discount. This is found right below the section where you enter your voucher code.

Pizza Customization

In the 'CUSTOMIZE' page (on navbar), users can customize their pizzas.

They can add an ingredient onto the base dough by clicking the following button:

Once the ingredient is added, it should be visible under the 'Preview' section.

PLEASE NOTE THAT: you can scroll down for more ingredients!

After adding as many ingredients as desired, click theblue 'ADD TO CART' button to finalize the pizza and add it to the cart.
The button looks like the following:

NOTE: The ingredients cannot be changed once added to the cart.

After adding to the cart, 'Custom Pizza' should be visible in the cart.

Checkout

Clicking the checkout button takes you to a page to review your order.
